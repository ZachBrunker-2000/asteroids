# Asteroids

A Python implementation of the classic Asteroids arcade game.

## Overview

This project recreates the iconic Asteroids game, where players control a spaceship to destroy asteroids and enemy ships while avoiding collisions. It's built with Python and provides an engaging retro gaming experience.

## Features

- Classic arcade-style gameplay
- Spaceship controls and shooting mechanics
- Asteroid physics and collision detection
- Score tracking and game states
- Retro visual style

## Requirements

- Python 3.x
- Dependencies listed in `requirements.txt` (if applicable)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/ZachBrunker-2000/asteroids.git
cd asteroids
```

2. Install any required dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the game with:
```bash
python main.py
```

## How to Play

- **Move**: Use arrow keys or WASD to move your spaceship
- **Shoot**: Press Space to fire bullets at asteroids
- **Objective**: Destroy all asteroids and enemy ships to advance levels
- **Avoid**: Colliding with asteroids will damage your ship
